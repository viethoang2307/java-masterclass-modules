# EX03 — Quản lý state trong JShell

Difficulty: Medium
Coverage: JShell, /vars, /list, /reset, /exit

## Bối cảnh

Bạn cần thử nhanh expression mà không tạo project.

## Yêu cầu

Tạo hai biến, xem state bằng /vars và /list, reset session rồi chứng minh biến cũ không còn.

1. Thực hiện lệnh và ghi output thật vào evidence-template.md.
2. Không chép version hoặc path từ máy khác.
3. Hoàn thành Main.answer() bằng kết luận của bạn.
4. Chạy SelfCheck và giải thích kết quả bằng lời.

## Lệnh gợi ý

- jshell
- /vars
- /list
- /reset
- /exit

## Chạy self-check

~~~powershell
javac --release 17 Main.java SelfCheck.java
java SelfCheck
~~~

## Tiêu chí hoàn thành

- Evidence có command, actual output, diagnosis và next action.
- SelfCheck in PASS - EX03.
- Bạn phân biệt được fact, assumption và recommendation.
