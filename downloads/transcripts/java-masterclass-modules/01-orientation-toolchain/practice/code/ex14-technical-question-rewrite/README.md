# EX14 — Cải thiện câu hỏi kỹ thuật

Difficulty: Very Hard
Coverage: Q&A quality, evidence, reproducibility

## Bối cảnh

Câu hỏi ban đầu chỉ nói Java không chạy, giúp tôi.

## Yêu cầu

Viết lại với tiêu đề cụ thể, mục tiêu, code tối thiểu, lỗi nguyên văn, version, lệnh đã chạy và điều đã thử.

1. Thực hiện lệnh và ghi output thật vào evidence-template.md.
2. Không chép version hoặc path từ máy khác.
3. Hoàn thành Main.answer() bằng kết luận của bạn.
4. Chạy SelfCheck và giải thích kết quả bằng lời.

## Lệnh gợi ý

- java --version
- javac --version

## Chạy self-check

~~~powershell
javac --release 17 Main.java SelfCheck.java
java SelfCheck
~~~

## Tiêu chí hoàn thành

- Evidence có command, actual output, diagnosis và next action.
- SelfCheck in PASS - EX14.
- Bạn phân biệt được fact, assumption và recommendation.
