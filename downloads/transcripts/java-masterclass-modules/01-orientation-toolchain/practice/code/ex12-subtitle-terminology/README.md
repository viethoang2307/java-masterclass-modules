# EX12 — Chuẩn hóa thuật ngữ từ subtitle

Difficulty: Hard
Coverage: subtitle, technical listening, terminology validation

## Bối cảnh

Subtitle dịch sai hoặc không nhất quán các từ compiler, runtime, statement và expression.

## Yêu cầu

Lập glossary song ngữ, đối chiếu context code và nguồn chính thức; đánh dấu từ không nên dịch máy móc.

1. Thực hiện lệnh và ghi output thật vào evidence-template.md.
2. Không chép version hoặc path từ máy khác.
3. Hoàn thành Main.answer() bằng kết luận của bạn.
4. Chạy SelfCheck và giải thích kết quả bằng lời.

## Lệnh gợi ý

- java --version

## Chạy self-check

~~~powershell
javac --release 17 Main.java SelfCheck.java
java SelfCheck
~~~

## Tiêu chí hoàn thành

- Evidence có command, actual output, diagnosis và next action.
- SelfCheck in PASS - EX12.
- Bạn phân biệt được fact, assumption và recommendation.
