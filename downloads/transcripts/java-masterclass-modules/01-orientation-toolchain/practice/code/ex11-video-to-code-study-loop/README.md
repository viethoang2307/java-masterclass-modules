# EX11 — Thiết kế study loop từ video tới code

Difficulty: Hard
Coverage: active learning, typing practice, feedback loop

## Bối cảnh

Người học xem hết video nhưng không thể tự viết lại code.

## Yêu cầu

Thiết kế chu kỳ xem ngắn, tự gõ, dự đoán output, chạy, ghi lỗi và ôn lại; có timebox và tiêu chí hoàn thành.

1. Thực hiện lệnh và ghi output thật vào evidence-template.md.
2. Không chép version hoặc path từ máy khác.
3. Hoàn thành Main.answer() bằng kết luận của bạn.
4. Chạy SelfCheck và giải thích kết quả bằng lời.

## Lệnh gợi ý

- java --version
- jshell

## Chạy self-check

~~~powershell
javac --release 17 Main.java SelfCheck.java
java SelfCheck
~~~

## Tiêu chí hoàn thành

- Evidence có command, actual output, diagnosis và next action.
- SelfCheck in PASS - EX11.
- Bạn phân biệt được fact, assumption và recommendation.
