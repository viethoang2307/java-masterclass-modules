# EX04 — Compile và chạy Hello World bằng CLI

Difficulty: Medium
Coverage: source, javac, bytecode, java launcher

## Bối cảnh

IDE không khả dụng nhưng JDK đã cài.

## Yêu cầu

Tạo HelloWorld.java, compile bằng javac, xác nhận file .class và chạy bằng java từ đúng working directory.

1. Thực hiện lệnh và ghi output thật vào evidence-template.md.
2. Không chép version hoặc path từ máy khác.
3. Hoàn thành Main.answer() bằng kết luận của bạn.
4. Chạy SelfCheck và giải thích kết quả bằng lời.

## Lệnh gợi ý

- javac --release 17 HelloWorld.java
- java HelloWorld

## Chạy self-check

~~~powershell
javac --release 17 Main.java SelfCheck.java
java SelfCheck
~~~

## Tiêu chí hoàn thành

- Evidence có command, actual output, diagnosis và next action.
- SelfCheck in PASS - EX04.
- Bạn phân biệt được fact, assumption và recommendation.
