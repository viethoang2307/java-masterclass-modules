# Lesson 001 — Course Introduction

## Mục tiêu bài học

Bài này định vị toàn bộ khóa học: người học có thể bắt đầu từ zero, chuyển từ ngôn ngữ khác sang Java, hoặc dùng để hệ thống hóa kiến thức đã biết. Course đi từ Java fundamentals tới OOP, Collections, Streams, I/O, concurrency, database, networking, testing, JavaFX và JPMS.

## Course nói gì?

Giảng viên nhấn mạnh ba điều:

1. Khóa học có lộ trình từ cơ bản tới nâng cao.
2. Nội dung được cập nhật theo JDK 17 trong bản remaster.
3. Học lập trình cần thực hành liên tục, không chỉ xem video.

## Mental model

Hãy coi khóa học như một dependency graph, không phải danh sách video độc lập:

    syntax
      -> control flow và methods
      -> classes và OOP
      -> collections/generics
      -> lambdas/streams
      -> I/O/concurrency
      -> database/network/UI/module

Nếu bỏ qua nền tảng, các module sau vẫn có thể xem nhưng khó hiểu cơ chế và trade-off.

## Điều cần làm sau bài

- Xác định mục tiêu: đi làm Java backend, desktop, học OOP, hay ôn interview.
- Chọn baseline JDK 17 để bám course.
- Tạo một thư mục source code riêng, commit từng milestone.
- Duy trì thói quen: xem một đoạn ngắn, tự gõ lại, sửa input, viết test hoặc challenge.

## Khi nào nội dung này hữu ích?

Hữu ích khi lập kế hoạch học dài hạn và tránh học ngẫu nhiên. Không nên hiểu lời giới thiệu là bảo đảm bạn sẽ thành thạo chỉ bằng cách hoàn thành video; năng lực đến từ việc tự viết và debug code.

## Pitfalls

- Xem hết video nhưng không chạy code.
- Nhảy vào framework trước khi hiểu Java core.
- Học theo thứ tự file archive thay vì dependency kiến thức.
- Dùng nhiều JDK/version trong cùng một project mà không ghi lại.

## Interview prompts

1. Bạn đã học Java theo lộ trình nào và vì sao?
2. Làm sao chứng minh mình hiểu chứ không chỉ xem tutorial?
3. Vì sao nên học core Java trước framework?

## Practice

Viết một trang learning contract gồm mục tiêu 8 tuần, số giờ mỗi tuần, project cuối khóa, tiêu chí “đã hiểu” và cách lưu code/test. Tạo repository local và commit file đầu tiên.

## Kết luận

Course cung cấp bản đồ; người học phải biến bản đồ thành năng lực bằng code, lỗi, test và reflection.
