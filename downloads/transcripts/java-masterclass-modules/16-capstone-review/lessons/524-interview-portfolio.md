- Problem/user và scope;
- architecture diagram;
- dữ liệu/error/concurrency boundary;

- metric/benchmark nếu có.

## Câu hỏi nên luyện

Vì sao chọn repository port? Làm sao tránh UI freeze? `requires transitive` khi nào nguy hiểm? Transaction rollback ra sao? Retry nào không nên làm? Test race thế nào?

Trả lời bằng code path và evidence cụ thể, không chỉ định nghĩa pattern.
