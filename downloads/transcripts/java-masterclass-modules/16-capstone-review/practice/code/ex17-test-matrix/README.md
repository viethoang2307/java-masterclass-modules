# Bài 17 — Test matrix completeness (Very Hard)

Mỗi requirement cần test types `happy`, `invalid`, `failure`. Trả ID thiếu một hoặc nhiều type; giữ thứ tự input, bỏ qua case null.

Mở rộng thực tế bằng `cancelled`, `concurrent` hoặc `security` tùy requirement, nhưng contract bài này yêu cầu ba loại nền.
