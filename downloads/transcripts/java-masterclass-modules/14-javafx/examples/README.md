# Examples — Module 14: JavaFX

Đây là specialization example. JavaFX không nằm trong JDK 17 mặc định; cần cài JavaFX SDK và chạy với module path.

Ví dụ trong folder này giữ contract về UI thread và prerequisite. Khi triển khai app thật, dùng Application.launch và sửa UI trên JavaFX Application Thread.
