# EX12 — String concatenation, equality và immutability

Difficulty: Hard
Coverage: String, + concatenation, equals, == pitfall, immutable

## Bối cảnh

## Yêu cầu

Chứng minh equals là true, không dùng == để kiểm tra nội dung, rồi chứng minh toUpperCase tạo String mới còn original không đổi.
