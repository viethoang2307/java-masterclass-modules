# EX17 — Expression report với args, String và primitives

Difficulty: Very Hard

## Bối cảnh

Tạo report nhận name, attempts, active và grade; kiểm tra output với Viet, 3, true, A.

Không hard-code output. Hãy để expression, type conversion và API phù hợp tạo ra kết quả.
