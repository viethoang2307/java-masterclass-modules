# EX05 — Primitive range và wrapper constants

Difficulty: Medium
Coverage: 8 primitives, Integer, Byte, Long, MIN_VALUE/MAX_VALUE

## Bối cảnh

Tạo báo cáo ngắn về giới hạn số nguyên mà không tự ghi nhớ sai range.

## Yêu cầu

In range của byte và int bằng Byte/Integer wrapper constants, kèm width của int.

Không hard-code output. Hãy để expression, type conversion và API phù hợp tạo ra kết quả.

## Starter contract

- Hoàn thành Main.result() hoặc các method được nêu trong đề.
- Giữ tên class là Main.
- Không dùng thư viện ngoài Java SE.
- Chạy SelfCheck trước khi xem lời giải.

## Chạy bài

~~~powershell
javac --release 17 Main.java SelfCheck.java
java SelfCheck
~~~

SelfCheck ban đầu có thể FAIL vì starter còn TODO. Kết quả hoàn thành phải là PASS - EX05.
