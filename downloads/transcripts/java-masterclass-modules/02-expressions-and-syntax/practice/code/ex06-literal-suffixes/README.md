# EX06 — Numeric literal và suffix

Difficulty: Hard
Coverage: long literal, float suffix, double literal, underscores

## Bối cảnh

Một báo cáo dùng số lớn và decimal nhưng compiler suy luận type khác mong đợi.

## Yêu cầu

Tạo long literal lớn hơn Integer.MAX_VALUE, float literal có hậu tố f và double literal; output chính xác cả ba giá trị.

Không hard-code output. Hãy để expression, type conversion và API phù hợp tạo ra kết quả.

javac --release 17 Main.java SelfCheck.java
