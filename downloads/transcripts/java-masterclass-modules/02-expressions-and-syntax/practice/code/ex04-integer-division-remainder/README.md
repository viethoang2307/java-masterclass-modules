# EX04 — Integer division và remainder

Difficulty: Medium
Coverage: int arithmetic, division, remainder, double division

## Bối cảnh

Bạn cần phân biệt phép chia nguyên với phép chia floating-point.

## Yêu cầu

Tính 5 / 2, 5 % 2 và 5.0 / 2; output là Int=2;Remainder=1;Double=2.5.

Không hard-code output. Hãy để expression, type conversion và API phù hợp tạo ra kết quả.

## Starter contract

- Hoàn thành Main.result() hoặc các method được nêu trong đề.
- Giữ tên class là Main.
- Không dùng thư viện ngoài Java SE.
- Chạy SelfCheck trước khi xem lời giải.

## Chạy bài

~~~powershell
javac --release 17 Main.java SelfCheck.java
java SelfCheck
~~~

SelfCheck ban đầu có thể FAIL vì starter còn TODO. Kết quả hoàn thành phải là PASS - EX04.
