# EX01 — main và Output Contract

Difficulty: Medium
Coverage: class, main, statement, String literal, println

## Bối cảnh

Viết chương trình nhỏ nhất có output xác định để kiểm tra toolchain.

## Yêu cầu

In chính xác Hello, Java 17! bằng một class Main có public static void main(String[] args).

Không hard-code output. Hãy để expression, type conversion và API phù hợp tạo ra kết quả.

## Starter contract

- Hoàn thành Main.result() hoặc các method được nêu trong đề.
- Giữ tên class là Main.
- Không dùng thư viện ngoài Java SE.
- Chạy SelfCheck trước khi xem lời giải.

## Chạy bài

~~~powershell
javac --release 17 Main.java SelfCheck.java
java SelfCheck
~~~

SelfCheck ban đầu có thể FAIL vì starter còn TODO. Kết quả hoàn thành phải là PASS - EX01.
