# EX10 — char, escape và UTF-16 code unit

Difficulty: Hard
Coverage: char, escape sequence, numeric conversion, String distinction

## Bối cảnh

Bạn cần phân biệt một char với String và quan sát giá trị số của ký tự.

## Yêu cầu

Dùng char A, newline và code point/code unit; output phải cho thấy A có code 65 và newline có code 10.

Không hard-code output. Hãy để expression, type conversion và API phù hợp tạo ra kết quả.

## Chạy bài

~~~powershell
javac --release 17 Main.java SelfCheck.java
java SelfCheck
~~~

Starter có thể FAIL vì còn TODO. Kết quả hoàn thành phải là PASS - EX10.
