# EX02 — Declaration, initialization và assignment

Difficulty: Medium
Coverage: variables, int, assignment, increment

## Bối cảnh

Một counter bắt đầu ở 10, tăng 5 rồi phải in cả giá trị đầu và cuối.

## Yêu cầu

Dùng biến int, thực hiện declaration/initialization/reassignment rõ ràng và trả về chuỗi Start=10;End=15.

Không hard-code output. Hãy để expression, type conversion và API phù hợp tạo ra kết quả.

## Starter contract

- Hoàn thành Main.result() hoặc các method được nêu trong đề.
- Giữ tên class là Main.
- Không dùng thư viện ngoài Java SE.
- Chạy SelfCheck trước khi xem lời giải.

## Chạy bài

~~~powershell
javac --release 17 Main.java SelfCheck.java
java SelfCheck
~~~

SelfCheck ban đầu có thể FAIL vì starter còn TODO. Kết quả hoàn thành phải là PASS - EX02.
