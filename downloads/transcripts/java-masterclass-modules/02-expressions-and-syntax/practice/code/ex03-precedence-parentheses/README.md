# EX03 — Precedence và parentheses

Difficulty: Medium
Coverage: expression, operands, precedence, grouping

## Bối cảnh

Cùng một nhóm số nhưng hai cách nhóm cho hai kết quả khác nhau.

## Yêu cầu

Tính 10 + 2 * 3 và (10 + 2) * 3; output phải là Without=16;With=36.

Không hard-code output. Hãy để expression, type conversion và API phù hợp tạo ra kết quả.

## Starter contract

- Hoàn thành Main.result() hoặc các method được nêu trong đề.
- Giữ tên class là Main.
- Không dùng thư viện ngoài Java SE.
- Chạy SelfCheck trước khi xem lời giải.

## Chạy bài

~~~powershell
javac --release 17 Main.java SelfCheck.java
java SelfCheck
~~~

SelfCheck ban đầu có thể FAIL vì starter còn TODO. Kết quả hoàn thành phải là PASS - EX03.
