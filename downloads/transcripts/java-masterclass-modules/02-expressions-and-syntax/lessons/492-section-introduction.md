# 492 — Section introduction: First Steps

## Vai trò của section

Đây là phần đặt nền cho toàn bộ Java track: Hello World, main method, keyword, variable, data type, expression, operator, primitive type và String.

Đừng xem đây là các mảnh rời. Một chương trình nhỏ đi qua chuỗi:

~~~mermaid
flowchart LR
    A["Class"] --> B["main method"]
    B --> C["Statement"]
    C --> D["Expression"]
    D --> E["Typed value"]
    E --> F["Output"]
~~~

## Cách học section

Mỗi lesson nên có ba lượt:

1. Đọc concept và từ khóa.
2. Tự gõ ví dụ tối thiểu.
3. Thay đổi một giá trị để quan sát quy tắc.

Ví dụ không chỉ chạy Hello World; hãy thay chuỗi, thêm biến, đổi int thành long và dự đoán compiler sẽ phản ứng thế nào.

## Definition of done

Bạn hoàn thành section khi có thể:

- viết class có main;
- đọc declaration như int count = 3;
- giải thích RHS của assignment là expression;
- phân biệt int division với floating-point division;
- giải thích vì sao byte + short cho kết quả int;
- nhận ra String là reference type, khác primitive.
