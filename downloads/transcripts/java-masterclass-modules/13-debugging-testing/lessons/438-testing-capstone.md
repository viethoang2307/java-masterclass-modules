# 438 — Testing capstone

Nhận một bug report, tạo minimal reproducer, debugger evidence, fix nhỏ, regression test và test matrix. Nộp command, input, expected/actual trước-sau, risk và cleanup.

Capstone đạt khi test fail trước fix, pass sau fix, toàn suite pass, không thread/resource leak và có lý do cho mỗi test boundary.
