# Bài 08 — Automatic module name (Hard)

Mô phỏng quy tắc filename: bỏ `.jar`, bỏ suffix version dạng `-2.1.0`, đổi dấu gạch nối/gạch dưới thành dấu chấm và collapse dấu chấm lặp. `music-core-1.0.jar` thành `music.core`.

Đây chỉ là heuristic; lesson 484 giải thích vì sao phải kiểm tra manifest/artifact thật.
