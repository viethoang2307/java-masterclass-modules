# Bài 04 — Readability graph (Medium)

Graph map module tới các module nó `requires`. Viết BFS/DFS trả lời module `from` có thể đi tới `target` hay không; coi module tự đọc chính nó là đúng.

Graph có thể có cycle trong input kiểm thử, vì vậy phải có visited set. Không suy luận từ package exports ở bài này.
