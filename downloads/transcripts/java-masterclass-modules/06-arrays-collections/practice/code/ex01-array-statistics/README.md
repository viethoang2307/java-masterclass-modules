# Exercise 01 — Array Statistics

**Độ khó:** Medium

## Yêu cầu

Hoàn thiện `statistics(int[])` để trả `Stats(min, max, sum, average)` cho array không rỗng. Không sort và không sửa input. Với `null` hoặc array rỗng, ném `IllegalArgumentException`.

## Tiêu chí

- Duyệt đúng một lần, dùng `long` cho tổng.
- Average là `double`.
- Giữ TODO trong starter cho tới khi bạn hoàn thành.
