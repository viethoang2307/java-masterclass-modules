# 400 — HTTP/2 và version policy

HTTP/2 multiplex nhiều stream trên một connection, header compression và khác biệt latency so với HTTP/1.1. `HttpClient.Version.HTTP_2` là preference, server/proxy có thể negotiate khác.

```java
HttpClient client = HttpClient.newBuilder().version(HttpClient.Version.HTTP_2).build();
```

Không giả định HTTP/2 luôn nhanh hơn; TLS, proxy, server support và workload quyết định.
