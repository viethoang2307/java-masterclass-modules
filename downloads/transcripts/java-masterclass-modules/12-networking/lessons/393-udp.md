# 393 — Datagram và UDP

UDP gửi datagram độc lập, không guarantee delivery, order hay duplicate-free; đổi lại ít handshake và phù hợp telemetry/discovery/real-time nơi application tự xử lý loss.

```java
DatagramPacket packet = new DatagramPacket(bytes, bytes.length, host, port);
socket.send(packet);
```

Giới hạn packet size để tránh fragmentation; protocol có thể thêm sequence, timestamp, checksum và retry có giới hạn. Không dùng UDP cho dữ liệu cần exactly-once nếu chưa thiết kế reliability layer.
