# Lesson 703 — Security và OAuth2

## Mục tiêu

Phân biệt authentication với authorization; bảo vệ endpoint; và không tự viết crypto/token handling thiếu kiểm chứng.

## Nội dung

- Password hashing và credential storage.
- Session, JWT và OAuth2 roles.
- Scope/role/authority.
- CORS/CSRF theo loại client.
- Secret/config rotation.
- Test unauthorized, forbidden và expired token.

## Bài tập

Vẽ request flow từ login tới protected expense endpoint; viết security matrix user/admin/guest và test các response 401/403.
