# Lesson 702 — REST, JSON và validation

## Mục tiêu

Thiết kế resource, HTTP method/status, DTO, validation, pagination và error response ổn định.

## Nội dung

- Resource naming và idempotency.
- Request/response DTO không expose entity.
- Bean validation và validation groups.
- Global exception handler.
- Error code, correlation id và pagination.
- Contract test cho JSON.

## Bài tập

Thiết kế API expense: create, list, get, update; viết OpenAPI-like contract, validation cases và error examples.
