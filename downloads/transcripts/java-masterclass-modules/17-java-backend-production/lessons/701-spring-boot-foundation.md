# Lesson 701 — Spring Boot foundation

## Mục tiêu

Hiểu application context, dependency injection, configuration, profiles, actuator và vì sao Spring Boot conventions giảm ceremony nhưng không thay thế thiết kế.

## Nội dung

- Component scanning và bean lifecycle.
- Constructor injection.
- Configuration properties và environment override.
- Profiles cho local/test/prod.
- Health/readiness endpoint.
- Maven plugin và executable JAR.

## Bài tập

Tạo service có local và test profile, constructor injection, health check và test context startup. Ghi rõ bean nào thuộc application boundary.
