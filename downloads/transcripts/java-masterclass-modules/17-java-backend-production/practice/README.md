# Practice — Module 17 Backend Production

Bộ practice sẽ được triển khai theo integration layers, không giả lập framework bằng một file Main.java.

## Các nhóm bài

1. Spring Boot configuration và profile.
2. REST controller với DTO/validation.
3. Global exception handler và error response.
4. Repository/service test với JUnit 5 và Mockito.
5. JDBC/JPA transaction.
6. Security rule và authentication boundary.
7. Redis cache hit/miss/invalidation.
8. Kafka producer/consumer, retry và idempotency.
9. Docker Compose local stack.
10. CI pipeline: test, package, image scan.

## Hợp đồng

- Java 17 và Maven.
- Mỗi lab có README, source, test và lệnh chạy.
- Integration test phải mô tả external dependency.
- Secret dùng environment variable, không commit vào repository.
- Các lab sẽ được thêm theo từng batch sau khi Module 13 testing/tooling hoàn tất.
