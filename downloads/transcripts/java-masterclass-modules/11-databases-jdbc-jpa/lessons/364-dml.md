# 364 — INSERT, UPDATE và DELETE

DML repository cần xác định row count, generated key và conflict behavior. `executeUpdate()` trả số row; 0 thường là not found hoặc stale version.

```java
try (PreparedStatement ps = c.prepareStatement(
        "update account set balance_cents = ? where id = ?")) {
    ps.setLong(1, cents); ps.setLong(2, id);
    if (ps.executeUpdate() != 1) throw new NotFoundException();
}
```

Delete nên có policy rõ: hard delete, soft delete, cascade hay restrict. Không nuốt duplicate key; map thành domain conflict.

## Bài tự luyện

Viết contract `updateVersioned(id, expectedVersion, newValue)` và giải thích optimistic conflict khi row count bằng 0.
