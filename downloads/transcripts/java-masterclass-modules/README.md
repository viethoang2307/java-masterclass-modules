# Java Masterclass — 16 Modules

Thư mục này chứa toàn bộ 16 module tài liệu học Java được chia theo lộ trình từ nền tảng đến capstone.

## Lộ trình

| Module | Chủ đề |
|---:|---|
| 01 | Orientation và Toolchain |
| 02 | Expressions và Syntax |
| 03 | Control Flow, Methods và Input |
| 04 | Classes và Object Model |
| 05 | OOP Design |
| 06 | Arrays và Collections |
| 07 | Generics, Nested Types và Lambdas |
| 08 | Streams và Core APIs |
| 09 | Regex, Exceptions và I/O |
| 10 | Concurrency |
| 11 | Databases, JDBC và JPA |
| 12 | Networking |
| 13 | Debugging và Testing |
| 14 | JavaFX |
| 15 | JPMS |
| 16 | Capstone và Review |

Mỗi module có `README.md`, `INDEX.md` và thư mục `lessons/`. Module 2 có thêm thư mục `examples/` chứa code Java chạy độc lập.

Transcript gốc vẫn được giữ ở thư mục cha để đối chiếu với tài liệu đã biên soạn.
