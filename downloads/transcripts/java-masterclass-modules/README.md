## Examples

Từ Module 2 đến Module 16, mỗi module có folder examples/ với README và ví dụ Java độc lập. Module 14 và 15 có prerequisite riêng được ghi trong README của examples.

## Backend branch

Sau Module 13, người học có thể đi theo nhánh:

~~~text
Spring Boot → REST/JSON → Security/OAuth2 → Redis
          → Kafka/Microservices → Docker → CI/CD/Observability
~~~

Nhánh này nằm ở [Module 17](17-java-backend-production/README.md). JavaFX và JPMS vẫn được giữ như specialization track, không làm chậm lộ trình Backend.

Mỗi module có README, INDEX và lessons. Các module có code practice ghi rõ command chạy và acceptance criteria. Transcript gốc vẫn được giữ ở thư mục cha để đối chiếu.
